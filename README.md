# Kifak · كيفك

Couples app for iPhone: take the quiz, connect, decode each other.

Start with **HANDOFF.md** — it has the full feature list, setup steps and what's left before launch.

```
npm install
npx expo install --fix
cp .env.example .env   # fill in keys
npx expo run:ios       # or BUILD_AND_SEND.bat for TestFlight
```
